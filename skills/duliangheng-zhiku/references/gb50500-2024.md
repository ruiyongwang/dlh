# GB/T 50500-2024 建设工程工程量清单计价标准 要点摘要

> 本文档为 2024 版清单计价标准的核心要点，供度量衡智库合同审查和造价争议调解使用。

---

## 一、标准概述

- **标准编号**: GB/T 50500-2024
- **标准名称**: 建设工程工程量清单计价标准
- **替代标准**: GB/T 50500-2013
- **实施日期**: [实施日期]
- **适用范围**: 建设工程施工发承包及实施阶段的计价活动

---

## 二、核心变化（相比 2013 版）

### 2.1 计价方式

| 项目 | 2013 版 | 2024 版 |
|------|---------|---------|
| 计价方式 | 单价为主 | 单价+总价结合 |
| 风险分担 | 固定比例 | 动态调整机制 |
| 价格调整 | 按合同约定 | 标准化调价公式 |
| 清单编制 | 三级编码 | 四级编码 |

### 2.2 风险分担原则

**不可调风险（承包人承担）**:
- 管理费
- 利润
- 一定幅度内的单价波动

**可调风险（发包人承担）**:
- 法律法规变化
- 政策性调整
- 超出约定幅度的价格波动
- 工程量偏差超出约定范围

---

## 三、价格调整机制

### 3.1 价格调整公式

```
ΔP = P₀ × [A + Σ(Bᵢ × Ftᵢ/F₀ᵢ) - 1]
```

**参数说明**:

| 参数 | 含义 | 取值范围 |
|------|------|---------|
| ΔP | 价格调整金额 | — |
| P₀ | 调价项目基准价格 | 按合同约定 |
| A | 定值权重 | 0.10 - 0.30 |
| Bᵢ | 第 i 种要素权重 | A + ΣBᵢ = 1 |
| Ftᵢ | 第 i 种要素当期价格指数 | 按官方发布 |
| F₀ᵢ | 第 i 种要素基准价格指数 | 按合同约定 |

### 3.2 调价要素

**主要调价要素**:

| 要素 | 权重参考 | 价格指数来源 |
|------|---------|-------------|
| 人工费 | B₁ = 0.15-0.25 | 造价管理部门 |
| 钢材 | B₂ = 0.10-0.20 | 市场价格信息 |
| 水泥 | B₃ = 0.05-0.10 | 市场价格信息 |
| 商品混凝土 | B₄ = 0.10-0.15 | 市场价格信息 |
| 燃料动力 | B₅ = 0.05-0.08 | 市场价格信息 |
| 机械费 | B₆ = 0.05-0.08 | 市场价格信息 |

### 3.3 调价触发条件

- 价格波动超过合同约定幅度（通常 ±5%）
- 法律法规变化导致成本变化
- 发包人原因导致工期延误期间的价格变化

## 四、工程量偏差处理

### 4.1 工程量偏差范围

| 偏差幅度 | 处理方式 |
|---------|---------|
| ≤ ±15% | 执行原综合单价 |
| > +15% | 超出部分综合单价调低 |
| > -15% | 全部工程量综合单价调高 |

### 4.2 工程量偏差计算公式

```
偏差率 = (实际工程量 - 清单工程量) / 清单工程量 × 100%
```

**超出 +15% 时**:
```
调整后综合单价 = 原综合单价 × (1 - 超出部分权重)
超出部分工程量 = 实际工程量 - 清单工程量 × 1.15
```

**低于 -15% 时**:
```
调整后综合单价 = 原综合单价 × (1 + 降低系数)
调整后工程量 = 实际工程量（按新单价计算）
```

## 五、清单缺陷处理

### 5.1 缺项漏项处理

| 缺陷类型 | 责任方 | 处理方式 |
|---------|--------|---------|
| 清单缺项 | 发包人 | 补充清单项，按新单价计价 |
| 清单漏项 | 发包人 | 补充清单项，按合同约定 |
| 特征描述不符 | 发包人 | 按实际特征调整单价 |
| 工程量偏差 | 双方 | 按偏差处理规则调整 |

### 5.2 新增项目计价

**计价顺序**:
1. 合同中已有相同项目的，执行已有单价
2. 合同中有类似项目的，参照类似单价
3. 合同中没有相同或类似项目的，按计价规范重新组价
4. 无法组价的，按市场价协商确定

## 六、索赔与签证

### 6.1 索赔时限

| 索赔类型 | 通知时限 | 证明材料提交时限 |
|---------|---------|----------------|
| 工期索赔 | 知道或应当知道索赔事件后 28 天内 | 28 天内 |
| 费用索赔 | 知道或应当知道索赔事件后 28 天内 | 28 天内 |
| 延期索赔 | 在索赔时效到期前提出延期申请 | — |

### 6.2 现场签证

**签证效力要求**:
- 发包人/监理工程师签字确认
- 签证内容与实际相符
- 签证时间与事件时间一致
- 签证事由和数量明确

## 七、结算与支付

### 7.1 预付款

| 项目 | 比例 | 扣回方式 |
|------|------|---------|
| 一般工程 | 10%-30% | 进度款中按比例扣回 |
| 重大工程 | 按合同约定 | 按合同约定 |

### 7.2 进度款

- 支付周期: 按月或按形象进度
- 支付比例: 不低于已完工程价款的 60%
- 竣工结算款: 竣工验收合格后 28 天内支付

### 7.3 质量保证金

| 项目 | 比例 | 返还时间 |
|------|------|---------|
| 保证金比例 | ≤ 3% | 缺陷责任期满后 14 天内 |

## 八、争议解决

### 8.1 争议处理流程

```
协商（28天）→ 调解（28天）→ 仲裁/诉讼
```

### 8.2 计价争议常见类型

| 争议类型 | 常见原因 | 处理依据 |
|---------|---------|---------|
| 单价争议 | 综合单价组价分歧 | 合同约定 + 计价规范 |
| 工程量争议 | 实际量与清单量偏差 | 现场核实 + 偏差处理规则 |
| 价格调整争议 | 调价公式适用分歧 | GB/T 50500-2024 |
| 变更计价争议 | 变更项目定价分歧 | 合同约定 + 类似项目参照 |
