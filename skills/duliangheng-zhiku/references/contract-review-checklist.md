# 合同审查检查清单

> 本清单用于建设工程合同审查，确保关键条款无遗漏。

## 一、合同基本信息检查

| 检查项 | 检查内容 | 状态 |
|-------|---------|------|
| 合同名称 | 合同名称是否准确 | ✅ / ⚠️ / ❌ |
| 合同编号 | 编号是否规范 | ✅ / ⚠️ / ❌ |
| 签订日期 | 是否填写 | ✅ / ⚠️ / ❌ |
| 合同金额 | 大小写是否一致 | ✅ / ⚠️ / ❌ |
| 合同期限 | 起止日期是否明确 | ✅ / ⚠️ / ❌ |

## 三、价款条款审查

### 3.1 计价方式

| 检查项 | 审查要点 | 风险等级 |
|-------|---------|---------|
| 计价方式 | 是否明确（总价/单价/成本加酬金） | 🟢 / 🟡 / 🔴 |
| 价格组成 | 是否包含全部费用（人工/材料/机械/管理费/利润/税金） | 🟢 / 🟡 / 🔴 |
| 暂列金额 | 暂列金额是否合理 | 🟢 / 🟡 / 🔴 |
| 暂估价 | 暂估价项目是否明确调价方式 | 🟢 / 🟡 / 🔴 |

### 3.2 支付条款

| 检查项 | 审查要点 | 风险等级 |
|-------|---------|---------|
| 预付款 | 比例是否合理（一般不超过合同价的10-30%） | 🟢 / 🟡 / 🔴 |
| 进度款 | 支付比例和时间是否明确 | 🟢 / 🟡 / 🔴 |
| 竣工结算款 | 结算期限和方式是否明确 | 🟢 / 🟡 / 🔴 |
| 质量保证金 | 比例是否符合规定（不超过3%） | 🟢 / 🟡 / 🔴 |
| 逾期付款 | 是否约定违约金或利息 | 🟢 / 🟡 / 🔴 |

### 3.3 价格调整

| 检查项 | 审查要点 | 风险等级 |
|-------|---------|---------|
| 调价机制 | 是否约定价格调整方式 | 🟢 / 🟡 / 🔴 |
| 调价范围 | 人工/材料/机械是否覆盖 | 🟢 / 🟡 / 🔴 |
| 调价基准 | 基准期和基准价格是否明确 | 🟢 / 🟡 / 🔴 |
| 调价幅度 | 是否设置调价幅度阈值（如±5%） | 🟢 / 🟡 / 🔴 |
