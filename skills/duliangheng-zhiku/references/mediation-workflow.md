# 商事调解工作流程

## 一、调解启动阶段

### 1.1 受理审查

**审查要点**:
- 争议是否属于商事调解范围
- 当事人是否具有主体资格
- 是否已进入诉讼/仲裁程序
- 争议金额和复杂程度

**受理条件**:
- ✅ 双方自愿申请
- ✅ 属于商事纠纷范围
- ✅ 争议事实基本清楚
- ❌ 涉及刑事犯罪
- ❌ 一方明确拒绝调解

### 1.2 调解准备

**信息收集清单**:
- 合同文件（原件或复印件）
- 变更签证记录
- 结算文件
- 来往函件
- 技术资料
- 会议纪要
- 其他相关证据

**当事人意愿确认**:
- 双方是否同意调解
- 调解期望和底线
- 授权范围确认
- 时间安排确认

---

## 二、事实查明阶段

### 2.1 争议焦点梳理

**梳理方法**:
1. 分别听取双方陈述
2. 梳理事实时间线
3. 识别争议核心问题
4. 确认无争议事实
5. 归纳争议焦点

**争议焦点分类**:
| 类型 | 描述 | 调解难度 |
|------|------|---------|
| 事实争议 | 对客观事实认定不一致 | 🟢 低 |
| 法律争议 | 对法律适用有分歧 | 🟡 中 |
| 金额争议 | 对款项数额有分歧 | 🟡 中 |
| 履行争议 | 对履行方式有分歧 | 🟡 中 |
| 综合争议 | 多种争议交织 | 🔴 高 |

### 2.2 证据审查

**证据审查标准**:
- 真实性：证据是否真实
- 合法性：证据获取方式是否合法
- 关联性：证据与争议是否有关联
- 完整性：证据链是否完整

**关键证据清单**:
- [ ] 合同及补充协议
- [ ] 变更签证
- [ ] 进度款支付凭证
- [ ] 竣工验收文件
- [ ] 结算审核报告
- [ ] 来往函件
- [ ] 会议纪要

### 3.2 方案设计

**方案设计原则**:
1. **合法合规**: 方案不违反法律法规强制性规定
2. **互利共赢**: 兼顾双方合理诉求
3. **可操作性**: 方案具有实际可执行性
4. **成本效益**: 调解成本低于诉讼/仲裁成本

**方案类型**:

| 方案类型 | 适用场景 | 优缺点 |
|---------|---------|--------|
| 金额折中方案 | 纯金额争议 | ✅ 简单直接 / ❌ 可能双方不满意 |
| 分期支付方案 | 业主资金紧张 | ✅ 缓解压力 / ❌ 周期长 |
| 工程量调整方案 | 工程量争议 | ✅ 客观公正 / ❌ 需鉴定 |
| 质量修复方案 | 质量争议 | ✅ 解决根源 / ❌ 时间成本 |
| 综合方案 | 复杂争议 | ✅ 全面解决 / ❌ 谈判难度大 |

### 3.3 方案评估

**评估维度**:
- 合法性（1-5分）
- 公平性（1-5分）
- 可操作性（1-5分）
- 双方接受度（1-5分）
- 成本效益（1-5分）

## 四、调解实施阶段

### 4.1 调解会议

**会议议程**:
1. 开场说明（5分钟）
2. 事实陈述（各方15分钟）
3. 争议焦点讨论（30分钟）
4. 方案讨论（30分钟）
5. 协商达成（30分钟）
6. 总结确认（10分钟）

**调解技巧**:
- 背靠背调解（分别沟通）
- 利益导向沟通
- 客观事实引导
- 期限压力策略
- 替代方案比较

### 4.2 方案调整

**调整原则**:
- 在合法范围内灵活调整
- 充分尊重当事人意愿
- 每次调整需双方确认
- 记录每次调整内容

## 五、调解协议阶段

### 5.1 协议起草

**协议必备条款**:
1. **当事人信息**: 名称、地址、法定代表人
2. **争议事项**: 争议的背景和焦点
3. **调解方案**: 双方达成一致的解决方案
4. **履行方式**: 履行的时间、地点、方式
5. **违约责任**: 违反协议的后果
6. **保密条款**: 争议和调解内容的保密
7. **争议解决**: 协议执行争议的解决方式

**协议模板**: 见 `assets/mediation-agreement-template.md`

### 5.2 司法确认

**司法确认条件**:
- 双方自愿达成调解协议
- 调解协议内容不违反法律规定
- 调解协议经双方签字确认
- 向有管辖权的人民法院申请

**司法确认流程**:
1. 起草司法确认申请书
2. 准备调解协议和证据材料
3. 向法院提交申请
4. 法院审查（一般15天内）
5. 裁定确认或不予确认

## 七、特殊场景处理

### 7.1 造价争议调解

**价格调整公式（GB/T 50500-2024）**:
```
ΔP = P₀ × [A + Σ(Bᵢ × Ftᵢ/F₀ᵢ) - 1]

参数说明:
- ΔP: 价格调整金额
- P₀: 基准价格
- A: 定值权重（不可调部分，通常 0.1-0.3）
- Bᵢ: 第 i 种要素的权重（A + ΣBᵢ = 1）
- Ftᵢ: 第 i 种要素的当期价格指数
- F₀ᵢ: 第 i 种要素的基准期价格指数
```

**清单缺陷处理**:
| 缺陷类型 | 处理方式 | 依据 |
|---------|---------|------|
| 缺项 | 按合同约定补充 | GB/T 50500-2024 |
| 漏项 | 按实际工程量调整 | 合同条款 |
| 特征不符 | 按实际特征调整 | 清单计价规范 |

### 7.2 工期延误调解

**关键因素**:
- 延误原因（业主/承包商/第三方/不可抗力）
- 延误天数
- 关键线路影响
- 实际损失计算
- 顺延工期合理性
