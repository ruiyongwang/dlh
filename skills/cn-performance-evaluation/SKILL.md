# 建设工程绩效评价 v2.0

## 核心定位

基于《政府投资条例》《中央预算内投资项目绩效管理办法》《PPP项目绩效管理操作指引》，提供建设项目全过程绩效管理服务。

## 专业法规依据

- 《政府投资条例》（国务院令第712号）
- 《中央预算内投资项目绩效管理办法》（发改投资〔2019〕10号）
- 《关于深化投融资体制改革的意见》
- 《PPP项目绩效管理操作指引》（财金〔2020〕13号）
- 《建设工程项目管理规范》GB/T 50326

## 核心能力

### 1. 事前绩效评估
- 项目立项必要性评估
- 绩效目标设定（产出/效益/满意度）
- 投资估算合理性分析
- 资金落实情况评估

### 2. 事中绩效监控
- 关键绩效指标（KPI）跟踪
- 资金使用进度监控
- 偏差分析与预警
- 纠偏措施建议

### 3. 事后绩效评价
- 四维评价指标体系
- 评价方法选择（成本效益法/比较法/公众评判法）
- 绩效评价报告编制
- 问题整改建议

### 4. PPP项目绩效管理
- 绩效目标编制
- 绩效监控与评价
- 绩效结果应用
- 按效付费机制

## 四维评价指标体系

| 维度 | 一级指标 | 二级指标示例 |
|------|---------|-------------|
| 决策 | 决策合理性 | 可研深度、立项规范性 |
| 过程 | 管理有效性 | 资金使用率、进度偏差率 |
| 产出 | 数量质量 | 完工率、合格率 |
| 效益 | 经济社会 | 投资回报率、社会效益 |

## 触发词

绩效评价、绩效管理、PPP绩效、政府投资绩效、项目后评价、绩效目标、绩效监控、绩效报告、绩效审计、按效付费、投资效益

## 使用场景

1. **政府投资项目**：中央预算内投资、地方财政投资项目的绩效管理
2. **PPP项目**：PPP项目的绩效评价与按效付费
3. **全过程咨询**：项目各阶段的绩效评估服务
4. **审计配合**：配合审计机关的绩效审计工作

## 输出成果

- 绩效目标申报表
- 绩效监控表
- 绩效评价报告
- 整改问题清单
- 绩效评价指标体系
