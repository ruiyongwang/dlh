# 绩效评价指标体系框架

## 一、政府投资项目绩效评价指标

### 决策指标（权重：20%）

| 二级指标 | 指标说明 | 评价方法 | 数据来源 |
|---------|---------|---------|---------|
| 决策程序规范性 | 项目立项、审批程序是否符合规定 | 文档审查 | 立项批复文件 |
| 可研深度 | 可行性研究论证是否充分 | 专家评审 | 可行性研究报告 |
| 绩效目标合理性 | 绩效目标是否明确、可衡量 | 比较分析 | 绩效目标申报表 |
| 投资估算准确性 | 估算与实际偏差情况 | 定量分析 | 概算/决算资料 |

### 过程指标（权重：30%）

| 二级指标 | 指标说明 | 评价方法 | 数据来源 |
|---------|---------|---------|---------|
| 资金到位率 | 实际到位资金/计划资金 | 定量计算 | 财务资料 |
| 资金使用率 | 实际支出/到位资金 | 定量计算 | 财务凭证 |
| 进度偏差率 | (实际进度-计划进度)/计划进度 | 定量计算 | 进度报告 |
| 管理规范性 | 管理制度执行情况 | 文档审查 | 管理制度文件 |
| 质量合格率 | 合格工程量/总工程量 | 定量计算 | 验收报告 |

### 产出指标（权重：30%）

| 二级指标 | 指标说明 | 评价方法 | 数据来源 |
|---------|---------|---------|---------|
| 计划任务完成率 | 实际完成/计划任务 | 定量计算 | 验收报告 |
| 建成资产完好率 | 完好资产/总资产 | 现场核查 | 资产清单 |
| 运营准备度 | 运营方案完备程度 | 专家评审 | 运营方案 |
| 服务能力 | 设计服务能力实现情况 | 对比分析 | 设计文件 |

### 效益指标（权重：20%）

| 二级指标 | 指标说明 | 评价方法 | 数据来源 |
|---------|---------|---------|---------|
| 经济效益 | 投资回报、运营收益 | 成本效益法 | 财务资料 |
| 社会效益 | 就业、环保、社会影响 | 公众评判法 | 调查问卷 |
| 生态效益 | 节能减排、环境改善 | 定量分析 | 监测数据 |
| 可持续性 | 项目长期运营能力 | 专家评审 | 运营方案 |

## 二、PPP项目绩效评价指标

### 项目识别阶段

| 阶段 | 绩效指标 | 权重 | 评价主体 |
|------|---------|------|---------|
| 立项 | 物有所值评价 | 15% | 财政部门 |
| | 可行性论证 | 10% | 行业主管部门 |
| | 风险分配 | 10% | 咨询机构 |

### 项目准备阶段

| 阶段 | 绩效指标 | 权重 | 评价主体 |
|------|---------|------|---------|
| 方案 | 绩效目标设定 | 20% | 财政部门 |
| | 产出说明 | 15% | 实施机构 |
| | 监测指标 | 10% | 实施机构 |

### 项目执行阶段

| 阶段 | 绩效指标 | 权重 | 评价主体 |
|------|---------|------|---------|
| 建设 | 建设进度 | 25% | 实施机构 |
| | 建设质量 | 25% | 监理单位 |
| | 安全管理 | 15% | 安全监督部门 |
| 运营 | 运营效率 | 20% | 实施机构 |
| | 服务质量 | 15% | 用户评价 |
| | 公众满意度 | 15% | 公众调查 |

## 三、评分等级

| 等级 | 得分区间 | 含义 |
|------|---------|------|
| 优秀 | 90-100分 | 绩效目标圆满实现 |
| 良好 | 80-89分 | 绩效目标基本实现 |
| 中等 | 60-79分 | 绩效目标部分实现 |
| 较差 | 40-59分 | 绩效目标实现较差 |
| 差 | 0-39分 | 绩效目标基本未实现 |
