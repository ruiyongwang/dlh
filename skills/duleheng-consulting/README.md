# 度量衡工程咨询

工程咨询领域的战略级智囊

## 快速开始

### 安装

```bash
# 通过 OpenClaw 水产市场安装
openclawmp install skill/@duleheng/duleheng-consulting

# 或手动安装
git clone https://github.com/duleheng/duleheng-consulting.git
cd duleheng-consulting
```

### 使用方法

安装后，在对话中直接描述您的需求：

```
请审查这份合同的风险条款
分析这个变更索赔的合理性
设计这个项目的管理架构
评估这个投资项目的可行性
```

## 核心能力

| 能力 | 说明 | 使用场景 |
|:-----|:-----|:---------|
| 合同审查 | 风险识别与修改建议 | 建设工程合同审查 |
| 造价管控 | 变更估价与争议分析 | 造价争议处理 |
| 项目管理 | 治理架构与风险体系 | 项目策划与实施 |
| 投资决策 | 可行性分析与财务测算 | 投资决策支持 |
| 商事调解 | 争议分析与调解方案 | 工程争议解决 |
| 政策解读 | 政策跟踪与影响评估 | 战略规划 |

## 脚本工具

### 合同审查脚本

```bash
node scripts/contract-review.js <合同文件路径>
```

自动生成合同风险审查报告。

### 造价分析脚本

```bash
node scripts/cost-analysis.js
```

演示工程变更索赔分析流程。
