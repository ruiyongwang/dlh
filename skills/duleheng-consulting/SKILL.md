# 度量衡工程咨询

> 工程咨询领域的战略级智囊 —— 让复杂决策更简单，让专业价值更可见。

## 核心能力

### 1. 合同审查 (Contract Review)

**适用场景：**
- 建设工程合同审查
- FIDIC条款分析
- EPC合同风险评估
- 合同谈判支持

**使用方法：**
```
请审查这份合同的风险条款：[上传合同文件]
```

**输出内容：**
- 风险条款识别与标注
- 不利条款修改建议
- 谈判要点清单
- 合同风险评级

---

### 2. 造价管控 (Cost Control)

**适用场景：**
- 投资估算审核
- 工程变更估价
- 结算争议分析
- 全过程造价咨询

**使用方法：**
```
分析这个变更的合理性：[变更单内容]
```

**输出内容：**
- 量价分析
- 争议焦点识别
- 处理建议
- 类似案例参考

---

### 3. 项目管理 (Project Management)

**适用场景：**
- 项目治理架构设计
- 风险管理体系构建
- 进度计划优化
- 多方协调机制

**使用方法：**
```
设计这个项目的管理架构：[项目概况]
```

**输出内容：**
- 组织架构方案
- 职责分工矩阵
- 风险管理清单
- 协调机制建议

---

### 4. 投资决策 (Investment Decision)

**适用场景：**
- 可行性研究报告审查
- 财务模型构建
- 风险评估与敏感性分析
- 投资决策建议

**使用方法：**
```
评估这个投资项目的可行性：[项目资料]
```

**输出内容：**
- 财务测算（NPV/IRR/回收期）
- 风险评估矩阵
- 敏感性分析
- 投资决策建议

---

### 5. 商事调解 (Commercial Mediation)

**适用场景：**
- 工程争议调解
- 索赔与反索赔分析
- 调解方案设计
- 调解协议起草

**使用方法：**
```
分析这个争议的调解策略：[争议情况]
```

**输出内容：**
- 争议焦点分析
- 各方利益评估
- 调解方案建议
- 协议条款草案

---

### 6. 政策解读 (Policy Intelligence)

**适用场景：**
- 行业政策跟踪
- 政策影响评估
- 趋势预判
- 应对建议

**使用方法：**
```
解读这个政策对行业的影响：[政策文件]
```

**输出内容：**
- 政策要点摘要
- 影响评估（行业/企业/项目）
- 趋势预判
- 应对建议

## 使用示例

### 示例1：合同审查

**用户输入：**
```
请审查这份施工合同的风险点
[上传合同文件]
```

**Skill响应：**
```
## 合同风险审查报告

### 高风险条款
1. **付款条款**（第X条）
   - 风险：付款节点不明确，可能导致资金占用
   - 建议：明确预付款、进度款、结算款的支付比例和时间

2. **变更条款**（第X条）
   - 风险：变更程序不完善，易引发争议
   - 建议：明确变更提出、审批、估价的全流程

### 中风险条款
...

### 谈判要点
1. 争取明确付款节点
2. 完善变更程序
3. ...

### 风险评级：⚠️ 中等风险
建议重点谈判付款和变更条款后再签署。
```

### 示例2：造价争议分析

**用户输入：**
```
这个变更索赔300万，合理吗？
[变更单详情]
```

**Skill响应：**
```
## 变更索赔分析报告

### 索赔构成
| 项目 | 申报金额 | 审核金额 | 差异 |
|:-----|:---------|:---------|:-----|
| 人工费 | 120万 | 85万 | -35万 |
| 材料费 | 100万 | 92万 | -8万 |
| 机械费 | 50万 | 45万 | -5万 |
| 管理费 | 30万 | 25万 | -5万 |
| **合计** | **300万** | **247万** | **-53万** |

### 争议焦点
1. 人工单价高于市场价15%
2. 材料损耗率计算偏高
3. ...

### 建议
- 合理区间：240-260万
- 谈判策略：...
```
