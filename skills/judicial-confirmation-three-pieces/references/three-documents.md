# 司法确认"三件套"文书详解

> 核心定义：《司法确认申请书》 + 《听证笔录》 + 《调解协议书》

---

## 一、三件套的完整定义

### 1.1 法律地位

司法确认"三件套"文书是商事调解（或人民调解）成果转化为司法强制力的**核心文书组合**，三者缺一不可：

```
┌─────────────────────────────────────────────┐
│            司法确认"三件套"文书              │
│                                             │
│  ┌──────────────┐  ┌──────────────┐       │
│  │ ①司法确认申请书 │→│ ②听证笔录     │       │
│  │ (启动文件)     │  │ (程序记录)    │       │
│  └──────────────┘  └──────────────┘       │
│          ↓                  ↓                │
│  ┌──────────────────────────────────┐     │
│  │ ③调解协议书                       │     │
│  │ (核心成果)                        │     │
│  └──────────────────────────────────┘     │
└─────────────────────────────────────────────┘
```

### 1.2 三者的逻辑关系

| 序号 | 文书 | 阶段 | 作用 | 法律属性 |
|:---:|------|------|------|---------|
| ① | 司法确认申请书 | **申请阶段** | 启动司法确认程序 | 当事人意思表示 |
| ② | 听证笔录 | **审查阶段** | 记录调解过程、审查自愿性与合法性 | 程序性证据 |
| ③ | 调解协议书 | **成果阶段** | 记载和解方案与权利义务 | 实体性协议 |

**核心逻辑**：**申请书**启动程序 → **听证笔录**证明程序合法 → **调解协议书**确认实体内容 → 法院出具**司法确认裁定书**（最终效力文书）

---

## 二、第一件：司法确认申请书

### 2.1 法律地位

**启动司法确认程序的法定文件**，必须由**双方当事人共同签署**后提交法院。

### 2.2 必备要素

```markdown
                    司法确认申请书

【申请人信息】
- 申请人（甲方）：名称、统一社会信用代码、住所地、法定代表人
- 申请人（乙方）：名称、统一社会信用代码、住所地、法定代表人

【申请事项】
请求贵院依法确认申请人双方于____年__月__日经________调解
达成的《调解协议书》（编号：××调字〔2026〕第×号）具有法
律效力。

【事实与理由】
1. 纠纷概况：双方因________（如：建设工程施工合同）产生争议
2. 调解过程：于____年__月__日共同委托________调解组织调解
3. 达成协议：经调解员主持，双方自愿达成调解协议
4. 法律依据：根据《民事诉讼法》第201条，请求司法确认

【附件清单】
1. 调解协议书原件1份
2. 身份证明/营业执照复印件
3. 法定代表人身份证明书
4. 授权委托书（如有）
5. 相关证据材料

【声明】
本人/本单位保证所提交材料真实、合法、有效，愿意承担虚假陈述的
法律责任。

申请人（甲方）：（盖章）
申请人（乙方）：（盖章）
申请日期：____年__月__日
```

### 2.3 关键要点

✅ **双方共同申请**：单方申请不予受理
✅ **30天时限**：自调解协议生效之日起30日内必须提交
✅ **内容完整**：当事人信息、请求事项、事实理由、附件清单缺一不可
✅ **真实承诺**：需有真实性、合法性声明

## 三、第二件：听证笔录

### 3.1 法律地位

**记录调解过程、审查自愿性与合法性的核心程序文件**，是法院判断调解协议是否应予确认的重要依据。

### 3.2 听证程序全流程

```
┌─────────────────────────────────────────┐
│           听证程序流程图                 │
├─────────────────────────────────────────┤
│                                         │
│  1. 核对当事人身份                       │
│     ↓                                   │
│  2. 宣布听证纪律与权利义务               │
│     ↓                                   │
│  3. 申请人陈述调解协议内容               │
│     ↓                                   │
│  4. 调解员介绍调解过程                   │
│     ↓                                   │
│  5. 审查自愿性（是否胁迫、欺诈）         │
│     ↓                                   │
│  6. 审查合法性（是否违法、损公益）       │
│     ↓                                   │
│  7. 当事人最后陈述                       │
│     ↓                                   │
│  8. 宣布听证结束                         │
│                                         │

```

### 3.4 核心审查内容

#### 3.4.1 自愿性审查（必查）

| 审查要点 | 询问方式 | 证据要求 |
|---------|---------|---------|
| 是否自愿参与调解 | "是否自愿接受调解？" | 当事人明确答复 |
| 有无胁迫、欺诈 | "是否受到威胁、欺骗？" | 当事人声明无胁迫 |
| 是否理解协议内容 | "是否清楚协议法律后果？" | 当事人确认理解 |
| 是否自主签署 | "是否自愿签字盖章？" | 现场签字录像或见证 |

#### 3.4.2 合法性审查（必查）

| 审查类型 | 具体内容 | 建设工程特别注意 |
|---------|---------|----------------|
| **主体合法** | 当事人有完全民事行为能力 | 核对营业执照、授权书 |
| **内容合法** | 不违反法律强制性规定 | 不得涉及违法转包、挂靠 |
| **程序合法** | 调解程序符合规定 | 调解员资质、回避制度 |
| **公益保护** | 不损害公共利益 | 不得损害农民工工资权益 |
| **第三方利益** | 不损害第三人合法权益 | 不得损害小股东、债权人 |

### 3.5 听证笔录的关键作用

✅ **程序合法性证明**：证明调解过程符合法定程序
✅ **自愿性证据**：当事人亲口确认自愿达成调解
✅ **合法性审查依据**：记录法院对协议合法性的审查过程
✅ **强制执行前置条件**：无听证笔录，法院难以确认协议效力

## 四、第三件：调解协议书

### 4.1 法律地位

**调解活动的核心成果**，是当事人权利义务的最终约定，也是司法确认的对象。

### 4.2 建设工程纠纷调解协议书必备条款

```markdown
                    调解协议书

编号：××调字〔2026〕第×号

【当事人信息】
甲方（建设单位）：名称、地址、法定代表人
乙方（施工单位）：名称、地址、法定代表人
（如涉及分包、材料商等，继续列明丙方、丁方）

【纠纷事实】
一、工程项目概况
   工程名称：________
   工程地点：________
   合同金额：________元
   施工期限：____年__月__日至____年__月__日

二、争议事项
   1. 工程款支付争议：甲方欠付工程款____元
   2. 工期延误争议：延误____天，责任归属
   3. 质量争议：________（具体问题）
   4. 其他争议：________

【协议内容】
第一条 工程款确认与支付
1.1 双方确认：甲方尚欠乙方工程款人民币____元（大写：________）
1.2 付款计划：
    (1) 本协议生效后15日内支付____元；
    (2) 2026年__月__日前支付____元；
    (3) 余款____元于2026年__月__日前付清。
1.3 支付方式：银行转账至乙方指定账户
      开户行：________
      账号：________

第二条 工期与质量处理
2.1 工期延误：双方确认工期顺延____天，互不追究违约责任
2.2 质量问题：乙方于____年__月__日前完成整改，甲方验收合格后支付相应款项
2.3 验收标准：按照国家现行施工质量验收规范执行

第三条 债权债务处理（如涉及多方）
3.1 丙方将其对丁方的债权____元转让给乙方
3.2 债权转让通知于本协议生效后10日内完成
3.3 丁方直接向乙方履行付款义务

第四条 违约责任
4.1 甲方逾期付款：每逾期一日，按应付金额的万分之五支付违约金
4.2 乙方逾期整改：每逾期一日，按应整改部分造价的万分之五支付违约金
4.3 违约金上限：不超过应付/应整改金额的10%

第五条 保密条款
双方对调解过程中知悉的商业秘密、技术信息负有保密义务，不得向第三方泄露

第六条 争议解决
本协议履行过程中发生争议，双方应友好协商；协商不成，按原合同约定方式解决

【生效条款】
本协议自各方签字盖章之日起生效

【签署】
甲方（盖章）：________  法定代表人/授权代表（签字）：________
乙方（盖章）：________  法定代表人/授权代表（签字）：________
丙方（盖章）：________  法定代表人/授权代表（签字）：________（如有）

调解员（签字）：________
调解组织（盖章）：________

签订日期：____年__月__日

【附件】
1. 工程结算单
2. 质量检测报告（如有）
3. 相关签证、变更文件
```

### 4.3 调解协议书的生效要件

✅ **书面形式**：必须采用书面形式，口头协议无效
✅ **三方签署**：当事人 + 调解员 + 调解组织（缺一不可）
✅ **内容明确**：权利义务、履行方式、期限、违约责任清晰具体
✅ **意思真实**：无欺诈、胁迫、重大误解等情形
✅ **不违法**：不违反法律强制性规定，不损害公共利益和他人权益

### 4.4 建设工程纠纷特别注意事项

| 风险点 | 防范措施 |
|-------|---------|
| 工程量争议 | 附详细结算单，双方签字确认 |
| 质量标准不清 | 引用具体规范标准，明确验收程序 |
| 付款条件模糊 | 明确付款时间、金额、方式、账户 |
| 多方关系复杂 | 所有关联方共同签署，明确各自权利义务 |
| 质保金问题 | 明确质保金金额、扣留期限、返还条件 |
| 发票问题 | 约定开票时间、类型、税率 |

### 5.2 法院审查流程

```
┌─────────────────────────────────────┐
│        法院司法确认审查流程          │
├─────────────────────────────────────┤
│                                      │
│  ① 立案审查（形式审查）              │
│     → 申请材料是否齐全               │
│     → 是否属于法院管辖               │
│     → 是否在30天申请期限内           │
│                                      │
│  ② 实质审查                          │
│     → 审查听证笔录（程序合法性）     │
│     → 审查调解协议书（内容合法性）   │
│     → 必要时询问当事人/调解员        │
│                                      │
│  ③ 作出裁定                          │
│     → 符合规定：确认协议有效         │
│     → 不符合：驳回申请               │
│                                      │
└─────────────────────────────────────┘
```

### 5.3 审查重点对照表

| 审查文书 | 审查要点 | 建设工程特别注意 |
|---------|---------|----------------|
| **司法确认申请书** | 双方共同申请、30天时限、管辖正确 | 工程所在地法院管辖 |
| **听证笔录** | 自愿性审查、合法性审查、程序合规 | 重点审查是否损害农民工权益 |
| **调解协议书** | 内容明确、不违法、不损公益 | 不得涉及违法转包、挂靠 |

## 六、常见问题与解答

### Q1：三件套中哪件最重要？

**答**：三件都重要，缺一不可：
- **申请书**是启动钥匙，无申请不启动
- **听证笔录**是程序保障，无笔录难确认
- **调解协议书**是核心成果，无协议无内容

### Q2：没有听证笔录可以申请司法确认吗？

**答**：不可以。听证笔录是证明调解过程合法、当事人自愿的关键证据。没有听证笔录，法院无法审查调解协议的自愿性与合法性，将驳回申请。

### Q3：听证笔录和调解笔录有什么区别？

**答**：
- **调解笔录**：记录调解过程中的协商、让步、方案讨论
- **听证笔录**：专门记录司法确认前的审查听证，重点审查自愿性与合法性

实务中，调解组织应在调解成功后专门组织司法确认听证，制作听证笔录。

### Q4：三件套可以后补吗？

**答**：
- **申请书和调解协议书**：必须在30天申请期限内提交
- **听证笔录**：应在调解成功后、申请司法确认前完成

超过30天期限，无法补救，只能重新调解或直接起诉。

### Q5：建设工程纠纷调解协议要注意什么？

**答**：
1. **工程量明确**：附双方签字确认的结算单
2. **质量标准清晰**：引用国家规范，明确验收程序
3. **付款计划具体**：金额、时间、账户明确
4. **多方关系清晰**：总包、分包、材料商等所有关联方共同签署
5. **违法条款排查**：不得涉及转包、挂靠等违法行为

## 七、度量衡智库实务建议

> **作为建设工程商事调解实践者，特别提示：**

1. **调解前准备三件套模板**：提前准备标准模板，调解成功立即填写
2. **听证程序不可省略**：即使双方无争议，也必须正式听证并制作笔录
3. **30天时限严管理**：调解协议生效后立即启动司法确认申请流程
4. **建设工程纠纷"打包"**：同一项目的关联纠纷一揽子调解、一次性确认
5. **合法性审查前置**：调解协议草案应预先审查，避免违法条款导致确认失败
6. **保密条款必备**：工程报价、技术方案等商业秘密必须在协议中约定保密
