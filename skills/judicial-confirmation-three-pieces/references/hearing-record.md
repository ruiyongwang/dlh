# 听证笔录专章：制作规范与审查要点

> 听证笔录是司法确认"三件套"中的第二件，是证明调解程序合法、当事人自愿的关键证据。

---

## 一、听证笔录的法律地位

### 1.1 核心作用

听证笔录在司法确认程序中具有以下不可替代的作用：

| 作用 | 说明 |
|------|------|
| **程序合法性证明** | 证明调解过程符合法定程序 |
| **自愿性证据** | 当事人亲口确认自愿达成调解 |
| **合法性审查依据** | 记录法院对协议合法性的审查过程 |
| **强制执行前置条件** | 无听证笔录，法院难以确认协议效力 |

### 1.2 法律依据

-  **《民事诉讼法》第201条**  ：司法确认程序的基本要求
-  **《人民调解法》第33条**  ：调解协议可申请司法确认
-  **《关于人民调解协议司法确认程序的若干规定》**  ：要求审查自愿性与合法性
- **各地法院司法确认指引**：明确要求制作听证笔录

## 二、听证程序全流程

### 2.1 流程图

```
┌──────────────────────────────────────────┐
│           听证程序流程图（标准版）         │
├──────────────────────────────────────────┤
│                                          │
│  1. 准备阶段                              │
│     → 确定听证时间、地点                 │
│     → 通知当事人、调解员                 │
│     → 准备听证提纲                       │
│                                          │
│  2. 开始阶段                              │
│     → 主持人宣布听证开始                 │
│     → 核对当事人身份                     │
│     → 宣布听证纪律与权利义务             │
│                                          │
│  3. 陈述阶段                              │
│     → 申请人陈述调解协议内容             │
│     → 调解员介绍调解过程                 │
│     → 当事人补充说明                     │
│                                          │
│  4. 审查阶段（核心）                      │
│     → 审查自愿性（是否胁迫、欺诈）       │
│     → 审查合法性（是否违法、损公益）     │
│     → 审查可执行性（内容是否明确）       │
│                                          │
│  5. 结束阶段                              │
│     → 当事人最后陈述                     │
│     → 主持人宣布听证结束                 │
│     → 核对笔录并签字                     │
│                                          │
└──────────────────────────────────────────┘
```

### 2.2 时间安排

- **一般时长**：30-60分钟
- **复杂案件**：可适当延长至90分钟
- **建设工程纠纷**：因涉及金额大、法律关系复杂，建议安排60分钟以上

### 3.2 正文内容

```
【听证过程】

一、主持人宣布听证开始
主持人（姓名）：现在宣布听证开始。本次听证是根据《中华人民共和国民事诉讼法》
第201条及相关规定，对申请人与被申请人达成的调解协议进行司法确认前的审查听证。

（一）宣布听证纪律
1. 听证参与人应遵守法庭/听证室纪律，不得喧哗、吵闹；
2. 发言应经主持人许可，不得随意打断他人发言；
3. 听证参与人应如实陈述，不得作虚假陈述；
4. 手机等通讯工具应调至静音或关闭状态。

（二）告知权利义务
主持人：根据法律规定，当事人享有以下权利：
1. 申请主持人、记录人回避的权利；
2. 陈述、申辩的权利；
3. 提供证据的权利；
4. 核对、修改、补充听证笔录的权利。

当事人应履行以下义务：
1. 如实陈述事实；
2. 遵守听证纪律；
3. 核对并签署听证笔录。

【询问回避】
主持人：当事人是否申请主持人或记录人回避？
申请人甲：不申请回避。
申请人乙：不申请回避。

二、核对当事人身份
主持人：请双方出示身份证明文件。
（当事人出示身份证明过程记录）

申请人甲：（出示营业执照原件）我是××建设工程有限公司法定代表人×××。
主持人：核对无误。

申请人乙：（出示身份证原件）我是××集团有限公司法定代表人×××。
主持人：核对无误。

三、申请人陈述调解协议内容
主持人：请申请人陈述调解协议的主要内容。

申请人甲：我方与乙方因××工程施工合同纠纷，经调解组织调解，达成以下协议：
1. 双方确认工程总造价为人民币5000万元，已支付4000万元，尚欠1000万元；
2. 乙方承诺于2026年6月30日前支付500万元，2026年12月31日前支付500万元；
3. 如乙方逾期支付，按日万分之五支付违约金。

主持人：申请人乙，对以上内容有无异议？
申请人乙：无异议，情况属实。

四、调解员介绍调解过程
主持人：请调解员介绍本案调解过程。

调解员（姓名）：本案于2026年3月20日受理，我担任调解员。经3次调解，具体过程如下：
第一次调解（3月22日）：双方陈述争议事实，确认工程款金额为争议焦点；
第二次调解（3月25日）：核对工程结算单，确认欠款金额1000万元；
第三次调解（3月28日）：协商付款期限，达成分两期支付的一致意见。

调解过程中，双方均自愿参与，未受到任何胁迫、欺诈。

五、审查自愿性
主持人：根据法律规定，法院需审查调解协议是否为双方自愿达成。现进行询问：

（一）是否自愿参与调解
主持人：请问申请人甲，你是否自愿参与本次调解？
申请人甲：完全自愿。

主持人：请问申请人乙，你是否自愿参与本次调解？
申请人乙：完全自愿。

（二）有无胁迫、欺诈
主持人：双方在调解过程中，是否受到过任何威胁、恐吓、欺骗？
申请人甲：没有，整个过程都是自愿的。
申请人乙：没有，调解员非常公正，我们是自愿达成协议的。

（三）是否理解协议内容
主持人：双方是否清楚调解协议的法律后果？
申请人甲：清楚，明白不履行的法律后果。
申请人乙：清楚，我们会按期履行。

（四）是否自主签署
主持人：调解协议上的签字盖章是否为你们本人/本单位的真实意思？
申请人甲：是的，是我公司法定代表人亲笔签字并加盖公章。
申请人乙：是的，是我本人签字并加盖公司公章。

六、审查合法性
主持人：下面审查调解协议内容的合法性。

（一）是否违反法律强制性规定
主持人：调解协议内容是否违反法律、行政法规的强制性规定？
申请人甲：不违反，内容是合法的。
申请人乙：不违反，我们咨询过律师，内容合法合规。

（二）是否损害公共利益
主持人：协议内容是否损害国家利益、社会公共利益？
申请人甲：不损害，这是正常的工程款支付。
申请人乙：不损害，我们愿意履行付款义务。

（三）是否损害第三人合法权益
主持人：协议内容是否损害其他债权人、小股东等第三人合法权益？
申请人甲：不涉及第三方权益。
申请人乙：这是我们双方的债务关系，不涉及第三方。

（四）建设工程特别审查（如涉及）
主持人：本协议是否涉及违法转包、挂靠等建筑法禁止行为？
申请人甲：不涉及，我们是合法的总承包关系。
申请人乙：不涉及，合同是合法有效的。

主持人：是否损害农民工工资权益？
申请人甲：我们已经支付了全部农民工工资，有工资发放记录。
申请人乙：我们承诺收到的款项优先支付农民工工资。

七、审查可执行性
主持人：最后审查协议内容的可执行性。

主持人：付款金额、期限、方式是否明确具体？
申请人甲：明确，总共1000万元，分两期支付。
申请人乙：明确，我们会按时打到对方账户。

主持人：违约责任是否清晰？
申请人甲：清晰，逾期按日万分之五支付违约金。
申请人乙：我们接受这个违约责任条款。

八、当事人最后陈述
主持人：听证即将结束，请双方作最后陈述。

申请人甲：希望法院确认协议效力，保障我方权益。
申请人乙：我们会严格按照协议履行，希望法院予以确认。

九、宣布听证结束
主持人：本次听证结束。请当事人核对笔录内容，确认无误后签字。听证笔录将作为司法确认的重要依据。

当事人核对笔录情况：
□ 核对无误  □ 已更正____处（具体说明更正内容）
```

## 四、听证笔录制作要点

### 4.1 必须记录的内容

#### 4.1.1 程序性事项（缺一不可）

| 序号 | 内容 | 记录要求 |
|:---:|------|---------|
| 1 | 听证时间、地点 | 精确到分钟，地址具体到房间 |
| 2 | 主持人、记录人姓名 | 全名，注明调解员资格证号 |
| 3 | 当事人基本信息 | 姓名/名称、身份证号/统一信用代码 |
| 4 | 身份核对过程 | 记录出示的证件类型、核对结果 |
| 5 | 回避询问 | 明确记录是否申请回避及答复 |

#### 4.1.2 实体性审查（核心内容）

| 审查维度 | 必须记录的问题 | 必须记录的答复 |
|---------|---------------|---------------|
| **自愿性** | 是否自愿参与调解？ | "是"或"否"，以及具体说明 |
| | 有无胁迫、欺诈？ | "无"，以及当事人声明 |
| | 是否理解协议后果？ | "理解"，以及确认表述 |
| | 是否自主签署？ | "是"，以及签署过程说明 |
| **合法性** | 是否违反法律强制性规定？ | "不违反"，及理由 |
| | 是否损害公共利益？ | "不损害"，及理由 |
| | 是否损害第三人权益？ | "不损害"，及理由 |
| **可执行性** | 内容是否明确具体？ | "明确"，及具体内容确认 |
| | 违约责任是否清晰？ | "清晰"，及违约条款确认 |

### 4.2 记录技巧

#### 4.2.1 语言要求

✅ **使用第一人称**："我是××公司的法定代表人"
✅ **记录原话关键句**：特别是对自愿性、合法性的确认语句
✅ **客观中立**：不添加记录人的主观判断
✅ **详略得当**：重点记录审查问题及答复，一般性过程可简写

#### 4.2.2 建设工程纠纷特别注意

```
# 必须额外记录的内容：

1. 工程基本信息
   - 工程名称、地点、合同金额
   - 施工范围、工期

2. 争议焦点确认
   - 欠款金额及计算依据
   - 工期延误天数及责任
   - 质量问题具体情况

3. 合法性专项审查
   - 是否涉及违法转包、挂靠？
   - 是否损害农民工工资权益？
   - 工程款优先受偿权是否放弃？

4. 可执行性确认
   - 付款计划是否具体（金额、时间、账户）
   - 整改方案是否明确（内容、标准、期限）
```

### 4.3 常见错误与规避

#### 4.3.1 常见错误

| 错误类型 | 具体表现 | 后果 |
|---------|---------|------|
| **形式错误** | 时间不具体、缺少签字 | 笔录无效，需重新听证 |
| **内容遗漏** | 未审查自愿性、合法性 | 法院不予确认协议效力 |
| **记录模糊** | 使用"大概""可能"等词语 | 证明力不足，需补充证据 |
| **签字不全** | 缺少调解员或记录人签字 | 程序瑕疵，影响效力 |
| **篡改笔录** | 事后修改未经当事人确认 | 笔录无效，涉嫌违法 |

#### 4.3.2 规避措施

✅ **制作听证提纲**：提前准备审查问题清单，确保不遗漏
✅ **现场录音录像**：重要案件全程录音录像，作为笔录补充
✅ **当事人确认**：结束前明确询问"以上记录是否准确？"
✅ **当场签字**：听证结束后立即签字，避免事后争议
✅ **保留原件**：笔录原件存档，复印件随司法确认申请提交

## 五、听证笔录的审查标准

### 5.1 法院审查要点

法院在司法确认时，对听证笔录的审查要点如下：

```
┌─────────────────────────────────────────┐
│        法院对听证笔录的审查清单          │
├─────────────────────────────────────────┤
│                                          │
│  ✓ 形式要件审查                          │
│    → 时间、地点是否明确                  │
│    → 当事人、主持人、记录人是否签字      │
│    → 笔录是否连续、有无涂改              │
│                                          │
│  ✓ 程序合法性审查                        │
│    → 是否履行回避告知义务                │
│    → 是否核对当事人身份                  │
│    → 是否宣布听证纪律                    │
│                                          │
│  ✓ 自愿性审查                            │
│    → 是否询问自愿参与调解                │
│    → 是否询问有无胁迫、欺诈              │
│    → 当事人是否明确答复"自愿"            │
│                                          │
│  ✓ 合法性审查                            │
│    → 是否询问是否违反法律规定            │
│    → 是否询问是否损害公共利益            │
│    → 是否询问是否损害第三人权益          │
│                                          │
│  ✓ 可执行性审查                          │
│    → 协议内容是否明确具体                │
│    → 履行方式、期限是否清晰              │
│                                          │
└──────────────────────────────────────────┘
```

### 5.2 审查结果处理

| 审查结果 | 法院处理 | 当事人应对 |
|---------|---------|-----------|
| **笔录完整、程序合法** | 确认协议效力 | 按裁定履行义务 |
| **笔录有瑕疵可补正** | 要求补正后重新审查 | 按要求补充材料 |
| **笔录严重违法** | 驳回司法确认申请 | 重新调解或直接起诉 |
| **无法判断自愿性** | 要求补充证据或重新听证 | 提供补充证据 |

## 六、建设工程纠纷听证笔录范例

### 6.1 典型案例背景

**纠纷类型**：建设工程施工合同纠纷  
**争议金额**：欠付工程款1000万元  
**调解结果**：分两期支付，2026年6月30日前付500万，12月31日前付500万  
**听证重点**：自愿性、合法性、可执行性审查

### 6.2 范例笔录（节选关键部分）

```
六、审查自愿性

主持人：下面进行自愿性审查。这是司法确认的核心要件，请双方如实回答。

（一）调解意愿的真实性
主持人：请问申请人甲，你们是否主动申请调解？有无受到外界压力？
申请人甲：我们是主动申请调解的。这个工程2024年就完工了，乙方一直拖着不付款，
我们本来想直接起诉的，但考虑到诉讼时间长、成本高，而且双方今后还想继续合作，
所以主动选择了调解。没有任何人强迫我们。

主持人：申请人乙，你们是否同意调解？
申请人乙：同意。我们确实欠付工程款，主要是因为业主方还没给我们结清款项，资金
周转困难。对方提出调解，我们也想尽快解决问题，避免诉讼对公司信誉的影响。

（二）调解过程的自愿性
主持人：在调解过程中，调解员有没有偏袒任何一方？
申请人甲：没有，调解员非常公正，耐心听取了双方意见。
申请人乙：调解员很专业，对建设工程领域的规则很熟悉，提出的方案我们都能接受。

主持人：有没有受到威胁、恐吓、欺骗？
申请人甲：绝对没有。
申请人乙：完全没有。

（三）协议签署的自主性
主持人：调解协议的内容，是否经过你们充分协商？
```

## 七、听证笔录制作清单

### 7.1 听证前准备清单

```
□ 确定听证时间、地点
□ 提前3天通知当事人、调解员
□ 准备听证提纲（问题清单）
□ 检查录音录像设备
□ 准备笔录用纸、笔
□ 准备当事人身份核对清单
□ 准备回避告知书（备用）
```

### 7.2 听证中必问问题清单

```
一、程序性问题（必问）
□ 是否申请回避？
□ 是否核对身份信息？

二、自愿性审查（必问）
□ 是否自愿参与调解？
□ 有无受到胁迫、欺诈？
□ 是否理解协议内容？
□ 是否自愿签署协议？

三、合法性审查（必问）
□ 是否违反法律强制性规定？
□ 是否损害公共利益？
□ 是否损害第三人合法权益？

四、可执行性审查（必问）
□ 协议内容是否明确？
□ 履行方式是否具体？
□ 违约责任是否清晰？

五、建设工程专项审查（如涉及）
□ 是否涉及违法转包、挂靠？
□ 是否损害农民工工资权益？
□ 工程款优先受偿权是否放弃？
```

### 7.3 听证后整理清单

```
□ 整理笔录，确保字迹清晰
□ 重点检查自愿性、合法性审查部分
□ 通知当事人核对签字
□ 主持人、记录人签字
□ 原件存档，复印件提交法院
□ 录音录像文件备份
```

## 八、总结

### 8.1 核心要点回顾

1. **听证笔录是司法确认的必备要件**，无笔录则无法确认
2. **自愿性审查是核心**，必须明确记录当事人"自愿"的意思表示
3. **合法性审查是底线**，建设工程纠纷要特别注意违法转包、农民工工资等问题
4. **形式规范是保障**，时间、地点、签字等要素缺一不可
5. **及时完成是关键**，应在调解成功后、申请司法确认前完成听证

### 8.2 度量衡智库特别提醒

> **建设工程商事调解听证笔录制作要诀：**

✅ **三个必问**："自愿吗？""违法吗？""明确吗？"  
✅ **三个必记**：当事人的原话、调解员的过程说明、审查结论  
✅ **三个必查**：转包挂靠、农民工工资、第三方权益  
✅ **两个必签**：当事人签字、调解员签字  
✅ **一个必存**：原件存档备查
