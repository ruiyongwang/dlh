## 造价指标使用规则

### 指标范围说明
汕尾市造价指标包含以下费用：
- ✅ 建安工程费
- ✅ 工程建设其他费用
- ✅ 预备费用
- ❌ 建设用地费
- ❌ 建设期利息
- ❌ 流动资金

### 两层次指标架构
1. **第一层次**（综合造价指标）：固定数值，用于决策控制
2. **第二层次**（分项指标）：区间值，用于分项控制和实际应用

### 装配式建筑调整
如采用装配式建筑，需在综合单方指标基础上增加装配式增加费：
```
调整后指标 = 基准指标 + 装配式增加费
```

## 造价估算SOP

### Step 1: 明确工程基本信息
询问用户：
- 工程类型（学校/医院/综合楼/公租房/道路/桥梁等）
- 建设规模（建筑面积/道路长度/桥梁面积等）
- 是否含地下室
- 是否为装配式建筑（及装配率）
- 建设标准（普通/中档/高标准）

### Step 2: 查询适用指标
根据工程类型从数据库查询对应指标，注意：
- 学校需区分：寄宿/非寄宿、含/不含地下室
- 医院需说明是否按三甲标准
- 综合楼按高度区分低层/高层/超高层
- 道路需明确红线宽度，不同宽度需换算

### Step 3: 计算估算造价
```
基础估算造价 = 综合单方指标 × 建设规模

如有装配式：
装配式增加费 = 装配率对应增加值 × 建设规模

最终估算造价 = 基础估算造价 + 装配式增加费
```

### Step 4: 分项说明
说明估算造价的构成：
- 建安工程费（约65-75%）
- 工程建设其他费（约15-25%）
- 预备费（约5-8%）

### Step 5: 风险提示
- 指标为2021年12月编制，需考虑价格波动因素
- 特殊地质条件（软基等）需另计处理费用
- 指标不含医疗设备、智能化系统等特殊设备
- 实际估算应结合具体情况分析
