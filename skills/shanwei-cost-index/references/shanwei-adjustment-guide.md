# 汕尾市造价指标调整说明

## 一、指标调整原则

本《估算指标》编制于2021年12月，适用于项目建议书和可行性研究报告阶段。

### 时间价格调整
- 指标基准期：2021年12月
- 如实际工程与指标编制时间差异较大，需参考以下价格变动因素进行调整：
  - 钢材价格指数变化
  - 混凝土材料价格变化
  - 人工费价格变化
  - 广东省发布的造价调整文件

### 规模调整说明
**道路工程宽度换算**：
- 基准红线宽度已在各项指标中注明
- 如实际宽度不同，需进行换算：
  ```
  调整后指标（万元/km）= 基准指标 × (实际宽度/基准宽度)^n
  n值参考：0.6-0.8之间
  ```

## 二、各类工程特殊调整

### 学校工程
1. **首层架空或连廊**：
   - 造价指标按水平投影面积 **2,000元/平方** 计算
   
2. **装配式建筑**：
   - 装配率30%-50%：在基准指标上增加 **150-250元/㎡**
   - 装配率50%-70%：增加 **250-400元/㎡**
   - 装配率>70%：增加 **400-600元/㎡**
   - 生均/床均指标作相应调整

3. **绿色建筑**：
   - 指标已包含绿色建筑增加费

4. **人防工程**：
   - 有地下室：已含人防工程设施费
   - 无地下室：已考虑人防易地建设费

### 医院工程
1. 基础指标按三甲医院标准测算
2. 以下费用**不包含**在指标中，需另计：
   - 医疗设备费
   - 智能信息化系统投资
   - 教学、科研、体检、保健设施
3. 如需设置人防医院，需另外增加相应费用

### 综合楼
1. 停车位配置标准：1个/100㎡建筑面积，停车位90%设于地下
2. 装配式建筑参照"1.1.8章节"调整
3. 指标已包含绿色建筑增加费和人防工程设施费

### 地下车库
- 基础指标为**地下负一层**
- 每增加一层，在基础指标上乘以**1.1系数**：
  - 地下二层：6,000 × 1.1 = 6,600元/㎡
  - 地下三层：6,000 × 1.1² = 7,260元/㎡

### 道路工程
1. **软基处理费需另计**（不包含在道路综合指标中）
2. 如道路红线宽度与基准宽度不同，需进行换算
3. 路面类型：指标按**沥青混凝土路面**研究，如采用其他路面需调整
4. **不含**监控系统费用

### 桥梁工程
1. 按桥梁投影面积计算（含桥面铺装、护栏）
2. 结构形式、跨径及地形条件不同时，在区间内选取
3. 特大型桥梁应根据桥梁具体方案确定造价指标
4. 人行天桥**不包含**雨棚、照明、绿化和其他景观工程

## 三、费用组成说明

### 指标包含费用
本指标包含以下三大部分：
```
总投资 = 建安工程费 + 工程建设其他费用 + 预备费用
```

**指标不包含**：
- ❌ 建设用地及拆迁费
- ❌ 建设期利息
- ❌ 流动资金
- ❌ 医疗设备、智能化系统等特殊设备

### 费用比例参考（汕尾市一般项目）
| 费用类别 | 占比 |
|---------|------|
| 建安工程费 | 65%-75% |
| 工程建设其他费 | 15%-22% |
| 预备费 | 5%-8% |

## 四、使用注意事项

1. **估算精度**：本指标为估算阶段参考指标，精度约±20%
2. **政策依据**：建设规模须经发改、财政及行业主管部门按规定核定
3. **偏差说明**：如估算明显偏离本指标，项目业主须在可研报告中进行造价合理性分析
4. **时效性**：指标编制时间为2021年，使用时需关注价格波动
5. **地域性**：指标适用于汕尾市区域，邻近地区参考使用时需酌情调整
